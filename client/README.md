# Silver Support Client 💻

실버 서포트 프로젝트의 프론트엔드 웹 어플리케이션입니다.

## 🛠️ 사용된 기술
- **React 19**: 최신 버전의 React 프레임워크
- **Vite**: 빠른 개발 환경과 빌드를 위한 빌드 도구
- **Tailwind CSS**: 유틸리티 우선 CSS 프레임워크
- **Radix UI**: 접근성 있는 비제어 UI 컴포넌트
- **Socket.io-client**: 서버와의 실시간 통신

## 🏃 실행 방법

### 개발 모드
```bash
npm run dev
```

### 빌드
```bash
npm run build
```

## 📁 주요 폴더 구조
- `src/components`: UI 컴포넌트 (Radix UI 기반 포함)
- `src/pages`: 대시보드, 요청, 서포터즈 등의 주요 페이지
- `src/lib`: 유틸리티 및 전역 함수
- `public/`: 정적 자원
